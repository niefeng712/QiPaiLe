# 棋牌乐

单机 + 同 WiFi 局域网联机的棋牌合集，仿 QQ 游戏大厅。用 **Godot 4** 开发，GitHub Actions 自动打包 **Windows `.exe`** 和 **Android `.apk`**，电脑和手机/平板可以在同一个 WiFi 下互通联机。

## 下载

到 [Releases](../../releases) 页面下载最新版：

| 设备 | 文件 | 说明 |
| --- | --- | --- |
| Windows 电脑 | `QiPaiLe-Windows-版本号.exe` | 免安装，双击运行。首次运行时请在防火墙弹窗中允许“专用网络” |
| Android 手机/平板 | `QiPaiLe-Android-版本号.apk` | 直接安装，横屏显示 |

## 怎么玩

- **单机**：在大厅选好游戏，点「单机游戏（和电脑玩）」，空位会自动由电脑补齐。
- **局域网联机**：所有设备连同一个 WiFi。一台点「创建局域网房间」，其他设备打开棋牌乐，大厅右侧会自动出现这个房间，点「加入」即可。找不到房间时，也可以输入房主的 IP 加入（房主 IP 显示在房间页面）。
- 房主可以把空位设为电脑、调整玩法规则，然后点「开始游戏」。
- 游戏中可以随时点「托管」让电脑代打；开了出牌倒计时的游戏，超时会自动处理，连续两次超时自动托管。
- 游戏中有人掉线，会由电脑临时托管；用同一个昵称重新加入就能接着玩。

## 大厅功能

- **分类浏览**：全部 / 扑克 / 麻将 / 棋类 / 休闲，每款游戏一张卡片，显示自己的战绩。
- **我的战绩**：每款游戏玩了几局、赢了几局、胜率，保存在本机，可以清空。
- **快捷聊天**：游戏中和房间里点「聊天」，可以发常用短语或自己输入（最多30字），所有人都能看到；电脑偶尔也会说话。
- **音效**：点击、出牌、轮到你、倒计时、胜利、失败、聊天提示音，全部用代码合成，大厅右上角可以开关。

## 技术结构

```
core/
  Net.gd           局域网核心：UDP 广播找房、ENet 联机、房间座位、电脑补位、掉线托管
  GameRegistry.gd  游戏注册表（大厅里显示哪些游戏、分类图标、每个游戏的玩法开关）
  Sfx.gd           音效（代码合成）
ui/
  GameCard.gd      大厅游戏卡片
scenes/
  Main.gd          大厅 / 房间 / 游戏界面（全部代码生成）
games/
  gomoku/          五子棋：GomokuLogic.gd（规则 + 电脑AI）、GomokuView.gd（界面）
  ludo/            飞行棋：LudoLogic.gd、LudoView.gd
  paodekuai/       跑得快：PdkRules.gd、PdkLogic.gd、PdkView.gd
  zhajinhua/       炸金花：ZjhLogic.gd（牌型/下注/比牌）、ZjhView.gd
  blackjack/       21点：BjLogic.gd、BjView.gd
  texas/           德州扑克：TexasLogic.gd（下注流程/边池/牌力）、TexasView.gd
  lianliankan/     连连看：LlkLogic.gd（连线判断/实时计时）、LlkView.gd
  junqi/           军棋：JqBoard.gd（四国/两国棋盘、铁路、碰子规则）、JunqiLogic.gd、JunqiView.gd
  xiangqi/         中国象棋：XqRules.gd（走法/将军判断/电脑搜索）、XiangqiLogic.gd、XiangqiView.gd
  checkers/        中国跳棋：CcRules.gd（121孔棋盘/走法）、CheckersLogic.gd、CheckersView.gd
  mahjong/         麻将：MjRules.gd（向听数/胡牌判定/电脑出牌）、MahjongLogic.gd（三种玩法）、MahjongView.gd
  tuolaji/         升级拖拉机：TljRules.gd（牌型/跟牌/甩牌判定）、TuolajiLogic.gd、TuolajiView.gd
  doudizhu/        斗地主：DdzRules.gd（牌型判定/提示，含癞子）、DoudizhuLogic.gd、DoudizhuView.gd
tests/
  run_tests.gd     规则测试：电脑对电脑整局模拟
.github/workflows/build.yml  自动检查 + 打包 + 发布
```

- **房主兼服务器**：所有规则判定都在房主那台设备上完成，其他人只发送操作、接收最新局面（状态同步）。
- **单机 = 不开网络的房主**：同一套代码，空位由电脑补齐。
- 端口：UDP `47800`（房间广播），UDP `47801`（游戏连接）。

## 新增一款游戏

1. 在 `games/<id>/` 下写 `XxxLogic.gd`（`setup / apply / get_state / current_seat / is_over / bot_action / bot_delay`；牌类游戏再加 `get_state_for(seat)` 只发自己的手牌，`round_scores()` 记累计分）和 `XxxView.gd`（`update_state / status_text`）。
2. 在 `core/GameRegistry.gd` 里登记，`ready` 设为 `true`，并配置玩法开关 `rules`。
3. 在 `tests/run_tests.gd` 里加一局电脑对电脑测试，然后推送，GitHub Actions 会自动检查并打包。

## 发布新版本

推送一个 `v` 开头的标签（例如 `v0.2.0`），Actions 会自动打包并发布到 Releases。安卓包使用固定签名（保存在仓库 Secrets 里），新版本可以直接覆盖安装。
